# Handoff protocol

`docs/STATE.md` is the mandatory concise handoff. Use this directory only for
larger, immutable handoff notes that do not fit there.

Every handoff records:

- the completed outcome and verification evidence;
- local files and AWS resources changed;
- the active spec-change status;
- unresolved risks, permissions, and owner inputs;
- the single recommended next step.

Do not record credentials, email addresses, account identifiers, or private
execution data.
